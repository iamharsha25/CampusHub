====================================================
               DATABASE RULES
====================================================

1. Every table has ONE Primary Key.

2. Foreign Keys always reference the Primary Key of another table.

3. One Teacher can guide many Students.

4. One Teacher can assign many Tasks.

5. One Teacher can review many Projects.

6. One Teacher can verify many Skills.

7. One Teacher can mark Attendance for many Students.

8. One Student belongs to one Teacher.

9. One Student can have many Projects.

10. One Student can have many Skills.

11. One Student can have many Tasks.

12. One Student can have many Attendance records.

13. One Student can submit many Placement Applications.

14. Store IDs instead of names for relationships.

15. Do not duplicate data across tables.

16. Every table represents one real-world entity.

17. Relationships are created using Foreign Keys.
